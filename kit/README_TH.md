# ParkingSite3D Kit — ย้ายงาน 3D ไปเครื่องอื่นให้ได้ผลเหมือนเดิมทุกอย่าง

## ในโฟลเดอร์นี้มีอะไร
| โฟลเดอร์/ไฟล์ | คืออะไร |
|---|---|
| `install.ps1` | ติดตั้งทุกอย่างบนเครื่องใหม่ (กดครั้งเดียว) |
| `verify.ps1` | ตรวจว่าเครื่องนี้สร้างโมเดลออกมา **ตรงกับเครื่องเดิม** หรือไม่ |
| `blender\` | Blender 5.3.0 ตัวเดียวกับที่ใช้สร้างงาน (ห้ามใช้เวอร์ชันอื่นกับงานนี้) |
| `skill\parking-site-3d\` | สกิลฉบับเต็ม (Hardware, อาคาร, พื้นผิว, ท้องฟ้า) |
| `projects\campus_5_gates\` | โปรเจกต์จริง 5 จุดตรวจ: แบบ 6 รูป, site_compact.json, ผลลัพธ์ `out_compact\` (เว็บ 3D อยู่ที่ `out_compact\web\index.html`) |
| `libraries\hardware_library\` | คลัง Hardware: `out\hardware_catalog.png`, เว็บ 3D `out\web\index.html` |
| `libraries\building_library\` | คลังอาคาร 4–10 ชั้น: `out\building_catalog.png`, เว็บ 3D `out\web\index.html` |
| `reference\` | "ลายนิ้วมือ" ของโมเดลที่อนุมัติแล้ว ใช้เทียบกับเครื่องใหม่ |
| `VERSION.txt` | เวอร์ชันโปรแกรมที่ล็อกไว้ |

## ขั้นที่ 1 — อัปโหลดขึ้น Google Drive (ทำที่เครื่องนี้)
1. เปิด drive.google.com
2. กด **+ ใหม่ → อัปโหลดโฟลเดอร์** แล้วเลือกโฟลเดอร์ `D:\ParkingSite3D_Kit` ทั้งโฟลเดอร์ (ประมาณ 600 MB)
3. รอจนอัปโหลดเสร็จ (ดูที่มุมขวาล่าง)

## ขั้นที่ 2 — ที่เครื่องใหม่ (ครั้งเดียว)
1. ติดตั้ง **Python 3.11** จาก python.org (ตอนติดตั้ง **ติ๊ก "Add python.exe to PATH"**)
2. ติดตั้ง **แอป Claude** แล้วล็อกอินบัญชีเดิม
3. ดาวน์โหลดโฟลเดอร์ `ParkingSite3D_Kit` จาก Drive (Drive จะให้มาเป็น zip) → **แตกไฟล์** ไว้ เช่น `D:\ParkingSite3D_Kit`
4. ในโฟลเดอร์นั้น คลิกขวา `install.ps1` → **Run with PowerShell**
   - ไม่ต้องลง Blender เอง ตัวติดตั้งแตก Blender 5.3.0 จากชุดนี้ให้
5. รอจนขึ้น **ALL MATCH** สีเขียว = เครื่องนี้สร้างโมเดลได้ตรงกับเครื่องเดิมทุกชิ้น
   - ถ้าขึ้น DIFFERENT สีแดง ให้ส่งข้อความนั้นให้ Claude ดู

## ขั้นที่ 3 — ใช้งาน
- เปิดแอป Claude แท็บ Code → เลือกโฟลเดอร์ `ParkingSite3D_Kit` แล้วสั่งงานได้เลย เช่น "แก้โปรเจกต์ campus_5_gates เพิ่มไม้กั้นที่จุด 3"
- ดูผลเดิมได้ทันทีโดยดับเบิลคลิก `index.html` ในโฟลเดอร์ `web\`

## กฎเพื่อให้ผลตรงกันเสมอ
- ใช้ Blender ตัวในชุดนี้เท่านั้น (Blender จาก Steam อัปเดตตัวเองได้ อาจทำให้หน้าตาเปลี่ยน)
- แก้สกิลที่เครื่องไหน ให้คัดลอกโฟลเดอร์ `skill\` และ `reference\` ใหม่ขึ้น Drive ทับของเดิม (หรือบอก Claude ว่า "อัปเดต kit")
- รัน `verify.ps1` ได้ทุกเมื่อเพื่อเช็คว่ายังตรงกัน
