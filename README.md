# Parking Site 3D

สกิล parking-site-3d สำหรับสร้างลานจอดรถ 3 มิติใน Blender พร้อมโมเดลอุปกรณ์ CREATIVE

- `skill/` สกิล (สคริปต์, assets, viewer)
- `kit/` สคริปต์ติดตั้งและ verify ของชุด kit
- `docs/` spec และ plan
- `tools/addon.py` Blender MCP addon

ไฟล์โมเดล .blend / .glb เก็บไว้ใน Google Drive
